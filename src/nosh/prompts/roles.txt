For each target, return the roles it plays in THIS dish, chosen only from the allowed list: binding, moisture, leavening, fat, thickening, flavor, texture, main_protein. Usually one to three roles. Also return up to three broader dish classes that a cook would consider the same kind of baked or cooked item as this dish (for banana bread: "quick bread", "muffin", "cake"; for a cream pasta: "cream sauce", "alfredo", "chowder"). Class names are short lowercase titles words, not ingredients.

Use only what is in the recipe text. Do not invent quantities, counts or numbers.
